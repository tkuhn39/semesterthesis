# Extension points (prepared, not implemented in stage 1)

Each item below is represented in the contracts today and raises `NotSupportedError` with a clear
message; a test asserts that behaviour so nothing is silently wrong. Adding the feature means removing
the guard and implementing the branch against its primary source.

| Extension | Contract hook today | Primary source for the future branch | Notes |
|---|---|---|---|
| Internal gears (Hohlräder) | `GearInput.kind = GearKind.INTERNAL`; `.ste` `ZAEHNEZAHL < 0` is parsed and mapped | DIN ISO 21771:2014 (internal-gear equations throughout §4–§7), DIN 21773:2014 §7.3 (Messlückenzahl), DIN 3960:1987 | sign conventions differ per norm; needed for planetary ring gears |
| Rack as a mating element (Zahnstange, z → ∞) | not a `GearInput`; a future `RackInput` | DIN ISO 21771:2014 §5 (limit case), STplus manual §5.3 | different from rack-type **tools**, which are the stage-1 core |
| Planetary stage | sun/planet already work as an external pair; ring gear needs internal branch | DIN ISO 21771:2014; DIN 3990-11 Annex B example | STplus manual §5.2 |
| Shaper cutter / profile tools | `ToolProfile.kind = ToolKind.SHAPER / PROFILE`; `.ste` `SR_*` / `PW_*` keys are parsed and kept | DIN 3960:1987 §3.6 (Schneidrad), DIN 1829; FVA 604 I (Flankengenerator) | envelope of a circular tool instead of a rack |
| Second tool / machining allowance | `GearInput.finishing_tool`, `ToolProfile.machining_allowance_mm`, `.ste` `WERKZEUG_FERTIGVERZ.`, `BEARBEITUNGSZUGABE`; `generation.pre_machining_generating_profile_shift_coefficient` (Eq. (120), (121)); `compute_generation` raises `NotSupportedError` for q > 0 | DIN ISO 21771:2014 §7.2, §7.4, Bild 36 b); DIN 3960:1987 Annex A.1, A.3.3; STplus manual §4.2 | pre-/finish-machined states (Vor-/Fertigverzahnung): the root and fillet of the pre-machining tool at x_EV, the flank of the finishing tool at x_E, d_Ff as their intersection (GEN-01) |
| Protuberance flank | `ToolProfile.protuberance_mm`, `protuberance_angle_deg`; `compute_generation` raises `NotSupportedError` | DIN 3960:1987 A.3.3; DIN ISO 21771:2014 §7.1; FVA 604 I Eq. (4.37) | root relief / Fußfreischnitt: one more tool element for the envelope of `trochoid.py`, the intersection with the finished involute (GEN-02, GEN-08) |
| Tool with a module or profile angle different from the gear's | `ToolProfile.normal_module_mm`, `profile_angle_deg` (the contract admits a tool that generates the same basic rack); `compute_generation` raises `NotSupportedError` | DIN ISO 21771:2014 §7.6 Bild 39 note (generating gear with alpha_wt0, d_wE); DIN 3960:1987 §3.6.1 | the generating pitch circle differs from the reference circle; `tool_normal_module` of the registry pending (GEN-03) |
| Topping tool | implemented 2026-10-03 (ADR-114): `ToolProfile.dedendum_factor`; `compute_generation` cuts a tip circle above the root line of the tool to d + 2 (x_E m_n + h_fP0), warning `tip_circle_cut_by_tool` | STplus manual p. 19 (the program uses the feasible tip circle), probes `tip_circle_cut_*`; DIN ISO 21771:2014 §7 uses no h_fP0 | a tooth made pointed by the edge break flanks (GEN-13) |
| Tool root rounding (tip rounding of the gear) | `ToolProfile.root_form_height_factor` without `edge_break_angle_deg` and a dedendum above it; `compute_generation` raises `NotSupportedError` where the straight flank ends below the tip circle. The `.ste` importer does not reach this: it sets the angle α_n0 + 10° with which STplus replaces the rounding (ADR-114) | DIN 3960:1987 Bild A.1 (ρ_fP0), Eq. (3.6.07) (d_Fa = d_a − 2 ρ_an (1 − sin α_an)); DIN ISO 21771:2014 §6.1.2 (Kopfkantenrundung); STplus manual p. 186 | one more tool element for the envelope of `trochoid.py` (GEN-10) |
| Non-circular tool tip (elliptic/free) | `.ste` `PW_KOPFART`, `PW_KOPF_XY`, `PW_KOPF_POLAR` parsed | STplus manual §4.16.2.4; Dong et al. 2020 (Bézier tip) | reuses the general envelope sampler |
| Tool referenced by name from the STplus tool database | `gearcore.stplus_program.tool_database()`, `stplus_tool(name)`; the `.ste` importer requires the tool block in the file | STplus manual p. 21 (tool files 1 to 10, local before global); ADR-109 | the importer would look the name up in the packaged databases; records that are no valid contract stay rejected |
| Distribution of the sum of the profile shift coefficients (only a_w given) | `PairInput` rejects a centre distance without any x; the `.ste` importer raises `NotSupportedError` for such a file, for `AUFTEILUNG_X1X2 = 1` and for `PR.VERSCH.SUMME` without the coefficient of one gear (with one coefficient the other follows, ADR-114) | DIN ISO 21771:2014 §5.3 (p. 42) leaves the distribution open; DIN 3992:1964-03 (withdrawn, in the repository) is what STplus offers | would be a named, explicit choice (ADR-107, ADR-109) |
| Other definitions of the tip circle | `io.ste.TIP_CIRCLE_KEYS`: a file that defines the tip circle of a gear without `KOPFKREISDM` by tip tooth thickness, by the tool, by the tip alteration of DIN 3960, by the tip clearance factor or by the addendum factor of the reference profile is `NotSupportedError`; beside `KOPFKREISDM` of both gears these keys have no effect in STplus and are named in a note | STplus manual Bild 4.12 (p. 25); probes `tip_circle_per_din3960` (k m_n = −0,126 mm), `tip_circle_from_reference_profile_addendum`; DIN ISO 21771:2014 Eq. (33) for the tip alteration (`pair.with_nominal_tip_diameters`) | `DA_NACH_DIN3960` first: Eq. (33) with k is in the package; the others need the criteria of STplus (GEN-15, GEN-16) |
| Chordal tooth thickness or x_F as an input | `io.ste.INSPECTION_KEYS_NOT_TRANSLATED` (`ZAHNDICKENSEHNE`, `ZAHNHOEHE_BEI_SEHNE`, `PROFILVERSCHIEBUNG_F`): `NotSupportedError` | DIN 21773:2014 §5 (inverse of Eq. (1) to (6)); STplus manual p. 16 | spans and ball dimensions as inputs are implemented (increment 4, ADR-115) |
| Double-flank centre distance with a master gear | none yet | DIN 21773:2014 §12, Eq. (38), (39), (64) to (66); DIN ISO 1328-2:2021 | increment 5 (user decision 2026-10-04) |
| Inspection dimensions of internal gears | `GearKind.INTERNAL` | DIN 21773:2014 §7.3, §9; DIN 3977:1981 section 6 (range for internal gears) | with the internal branch |
| Generating state selectable (upper, mean, lower allowance) | the generation uses the upper allowance | FVA Workbench attribute 15139 `switch_base_tangent_length_deviations`; DIN 21773 §4 | proposed for increment 5 |
| Load capacity, materials, fillet variants, FE | separate stages (see roadmap) | ISO 6336:2019 family, VDI 2736, patents/papers in `00_literatur` | contracts (`MaterialKind`, `MaterialRecord`) exist from stage 1 |
